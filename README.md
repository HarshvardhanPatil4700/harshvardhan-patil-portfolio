## 🧑‍💻 Getting Started

### 📋 Prerequisites

- [Node.js](https://nodejs.org/) (v16 or later recommended)
- npm (comes with Node.js)

### 📥 1. Clone the Repository

Repository: [harshvardhan-patil-portfolio](https://github.com/HarshvardhanPatil4700/harshvardhan-patil-portfolio)

```bash
git clone https://github.com/HarshvardhanPatil4700/harshvardhan-patil-portfolio.git
cd harshvardhan-patil-portfolio
```

### 📦 2. Install Dependencies

```bash
npm install
```

### ▶️ 3. Run the App

```bash
npm start
```

The app will be available at `http://localhost:3000`.

### 🏗️ 4. Build for Production

```bash
npm run build
```

The optimized production build is generated in the `build/` folder.

## 🎨 Customization

1. ✍️ **Content:** Update the text, links, and images inside the components in `src/components/`.
2. 🌈 **Theme:** Change colors, fonts, and spacing in `tailwind.config.js`.
3. 🧩 **Sections:** Add, remove, or reorder sections in `App.js`.

## 🌍 Deployment

This project is deployed on **Vercel**. To deploy your own copy:

1. Push your fork to GitHub.
2. Import the repository on [Vercel](https://vercel.com/new).
3. Keep the default settings and click **Deploy**.
